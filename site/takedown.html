Takedown Requests

This page explains how to request the removal of a report produced by the Soken Contract Review connector.

Who may request a takedown

  • The owner or operator of the reviewed smart contract code.
  • A party with a legitimate legal interest in the removal (for example, a copyright holder whose code was reviewed without authorisation).
  • The person who originally requested the review.

What to send

Email hello@soken.dev with the following:

  1. The report id or the URL of the report you want removed. If the report was published to GitHub or soken.dev/audits, include the public URL.
  2. Your name and the organisation you represent.
  3. A brief explanation of why you are requesting removal (for example: you own the reviewed code, the report contains inaccurate findings, or the report was produced from code you did not authorise for review).
  4. If you are the code owner, proof of ownership. The simplest form is a signed message from the contract's owner or admin address, or a commit to the repository adding a file with the report id. This is the same proof accepted by the claim page on soken.dev. If you cannot provide on-chain proof, describe how you are connected to the code.

What happens next

We aim to acknowledge your request within 2 business days and to act on it within 5 business days. These are targets, not guarantees.

When we act on a takedown:

  • If the sender proves ownership of the reviewed code, or if the report is wrong or abusive, we withdraw the report. Withdrawal removes the hosted page and the PDF from our servers. The report id and PDF hash continue to return a "Withdrawn" status on the authenticity check page.
  • If the report was published to the public GitHub repository and soken.dev/audits, we also remove the PDF from that repository and trigger a refresh of the site.
  • Tombstone records (containing only hashes and the withdrawal reason, not the report content) are kept indefinitely so that the authenticity check can confirm the report was withdrawn.

If we cannot verify the request or if the request does not fall within the categories above, we will explain why and suggest next steps.

Self-service deletion

If you are the person who requested the review, you can delete the job and its report at any time without contacting us:

  • Call the review_delete_job tool with the job id.
  • Use the manage page at the link provided in the report result.

This removes the source, findings, hosted page, and PDF from our servers. It does not remove a copy that was already published to GitHub through review_publish. For that, send a takedown email.

Contact

All takedown requests: hello@soken.dev
