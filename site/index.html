Soken Contract Review

An automated security review of smart contract source code, delivered as a PDF report. The connector runs as a remote MCP server operated by SOKEN LTD.

What it does

You give it a deployed contract address and chain, a public repository and commit, source files pasted in the conversation, or private code through a one-time upload link. The server pins the exact source, builds it in a sandbox, runs static analyzers, and maps entry points, roles, external calls and upgrade authority. Your language-model session reads the pinned code through read-only tools, confirms or dismisses each analyzer hit with quoted code, and submits findings. The server rejects code quotes that differ from the pinned lines, computes every count and total, and maps severity through a fixed matrix. The result is a PDF report hosted on soken.dev.

No person at SOKEN LTD reads the code or the findings before issue. This is an automated review, not a manual audit.

How to connect

Add the server URL to any MCP client (Claude.ai, Claude Code, Cursor, or others that support remote MCP servers):

https://mcp.soken.dev/mcp

No authentication is required. The connector exposes 19 tools. Start with review_start, follow progress with review_status, and retrieve the report with review_report.

Supported chains

  • EVM chains (Ethereum and EVM-compatible networks)
  • HyperEVM
  • TRON
  • Solana
  • TON
  • Aptos

Starknet and Sui are not supported at this time.

Supported languages

  • Solidity, Vyper (EVM, HyperEVM, TRON)
  • Rust: Anchor, native, Pinocchio (Solana)
  • FunC, Tact, Tolk (TON)
  • Move (Aptos)

Usage limits

Two reports per user per day. For requests relayed by shared infrastructure, the limit is counted per reviewed target, with a shared daily cap.

Publication

After a report is rendered, you may call review_publish with an explicit consent object to publish the report PDF to the public GitHub repository Soken-LTD/smart-contract-audits and to soken.dev/audits. Publication is automatic and labelled "Automated by SOKEN MCP". One published report per reviewed target (same contract address on the same chain, or same repository): a later published review of the same target replaces the earlier file. Published copies are permanent until a takedown request is honoured. See the Terms of Use for details.
